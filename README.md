Dapur Kilat — Warung Rush: a fast, original Indonesian warung cooking game. Take orders, chop, wok, plate and serve before the timer runs out. Built by an AI agent for make.fun's 'Make the best cooking game' bounty, $250 in USDC.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080 in a desktop browser. No build step, no dependencies — the game runs fully offline.

## Controls

- **WASD / arrow keys** — move the cook around the warung
- **E / Space** — interact: pick up, chop, wok, plate, serve
- **P** — pause
- **M** — mute
- **R** — restart
